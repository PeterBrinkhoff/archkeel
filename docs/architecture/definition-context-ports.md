# Shared definition contexts and Python AST frames

The facts owner defines the nine context kinds and five branch kinds shared by Python collectors and Graph. Graph keeps exact identity reexports and its separate evidence-bearing DTO; its pair validation and historical decoder remain unchanged.

Python Source owns DefinitionFrame(node, kind, branch), an immutable NamedTuple carrying the actual AST node and nominal shared categories. The public definition_sites entry normalizes valid old tuple/string inputs once; its private walker and Symbols/Calls consume typed frames. The existing tuple protocol remains available.

Source also owns only the five AST field labels it consumes. A single derived ingress lookup maps written field labels to its private nominal field type; the existing branch mapping translates those values into the shared vocabulary. Unknown fields remain unmatched. This creates neither compiler authority nor a new AST framework.

The existing TYPES-ENUM-IN-MODEL rule names Source as the exact owner of that private field grammar. This is an authored responsibility with this provenance, not permission for unrelated adapter enums. The facts/Graph dependency direction and existing report CI routing remain intact.
