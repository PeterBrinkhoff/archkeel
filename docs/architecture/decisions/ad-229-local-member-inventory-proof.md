# AD-229 Complete direct members retain local source proof

An unrelated resolver gap previously made every native member inventory partial.
This hid 37 complete Compass closed scopes and 26 complete Nest scopes, although
their lexical owners and directly declared members were fully collected.

At Core's existing validated-partial observation boundary, record a bound proof
in scope observations for complete native Dart and TypeScript inventories.
Do not change collected source facts, evidence, Target intent or global coverage.
Bind analyzer, producer, runtime, source and contract metadata, normalized source
records, permission/responsibility declarations, evidence and coverage failures.
The selected/resolution input listing must reproduce the native source digest;
every selected input must have been discovered, read and parsed.

Each eligible class needs a unique static owner binding and the collector's
complete inventory for the requested member kind. Its whole source library,
including declaration-contributing owned parts, must be free of coverage gaps.
All other gaps must have the recognized resolution-gap kind, source evidence and
consistent file/module/subject localization. Unknown metadata fails closed.
Conservatively veto every local gap, including signature-only gaps. Reject the
alternative of deleting the global coverage guard or interpreting diagnostic
prose to infer which declaration dimensions are affected.

The existing graph normalizer still checks exact member definition IDs and
native inventory completeness independently for each owner and kind. Inherited,
runtime-generated and unresolved members remain outside direct inventory proof.
This proof neither resolves signatures and calls nor certifies the whole UML
Target. A partial all-PASS comparison is retained only when the Target actually
declares a closed direct-member scope certified by this proof. Its evaluation
receipt remains incomplete; overall UML UNKNOWN and global coverage FAIL remain.
An unrelated certified inventory cannot expose a signature-only all-PASS Target.
Known missing or unexpected direct members still FAIL.

Replay validates the full bound proof against current recorded content. Stored
comparisons additionally bind the exact independent Target declaration. Legacy,
changed or malformed proof stays partial; permission, source, evidence and runtime
changes cannot replay certified PASS. Semantically invalid runtime metadata is
rejected even when a forged proof's marker matches that metadata. Late runtime or
contract diagnostics revoke proof before evaluation and canonical serialization.

Native tests cover unrelated/local gaps, owned Dart parts, missing/broken parts,
exact presence/absence, live/saved parity, deterministic repetition, all-PASS
retention and unrelated-proof withholding. Negative controls cover contradictory
gap fields, malformed metadata, stale content and late diagnostics. Frozen
Compass/Nest source and Target digests and every four-variant verdict remain
unchanged. Only justified direct-member completeness assessments become PASS.

This bounded correction for [#495](https://github.com/rapiddweller/archkeel/issues/495)
does not depend on the separate dependency-permission proof in #493. Existing
interfaces, policy, budgets, schemas and process protocol remain unchanged.
